Como publicar no GitHub Pages

Este site foi construído em um único arquivo (index.html) pronto para hospedagem gratuita:

  1. Crie uma conta gratuita no GitHub.com e clique em New Repository (ex: lista-de-casa).
  2. Envie este arquivo salvo exatamente com o nome index.html para dentro do repositório.
  3. No repositório, vá em Settings (Configurações) > Pages (menu lateral).
  4. Em Branch, selecione main e clique em Save.
  5. Em 1 minuto seu link estará no ar para compartilhar no WhatsApp com a família!

Passo importante no Firebase (Domínio Autorizado):

Como este arquivo já está conectado ao seu projeto casa-d8fb3, após ativar o GitHub Pages, vá no console do Firebase em Authentication > Settings > Authorized domains e adicione o seu domínio (ex: seu-usuario.github.io) para que o login anônimo funcione no site publicado.
